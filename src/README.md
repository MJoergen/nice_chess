# src

`mchess.c` is `runtime/libc/test/mchess.c` of
[nice_cpu](https://github.com/MJoergen/nice_cpu) at tag `V1.2`, unchanged.
It is MIT licensed, by the same author as this repository, and is the
starting point of the engine (doc/PORTING_PLAN.md, Phase 1).

The reference for the features it lacks is
[mchess2](https://github.com/MJoergen/mchess2) at commit `65e8855`, which
is not copied here.
